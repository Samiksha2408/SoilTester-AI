# SmartAgriAI

Frontend for the SmartAgriAI final-year project: soil analysis, crop and fertilizer planning, weather, reports and an AI assistant.

## Run

```bash
npm install
npm run dev
```

The UI uses mock data in `src/data/mockData.js`. Future HTTP calls live in `src/services/api.js`. Set `VITE_API_BASE_URL` when the backend is ready.
